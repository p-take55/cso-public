# CSO（戦略責任者）

ひとり社長と小さな事業のための戦略責任者エージェントです。月次の数字・問い合わせ・過去のやりとりを渡して話すと、次の6つを根拠つきの記録とHTMLの資料にまとめ、毎月・四半期ごとに更新します。

1. ミッション・ビジョン・経営方針（誰に何を届けるか、将来どういう事業にしたいか、何を重視して進めるか）
2. 事業環境分析（市場・競合・自社）
3. 事業戦略（候補の比較、ビジネスモデルキャンバス、試しの上限と判定基準）
4. 計画と予算（数年分の数字、月次予算、毎月見る数字）
5. 月次経営会議（予算と実績の差、決めること3つまで）
6. 四半期レビュー（前提の点検と、戦略・計画・経営方針の新しい版）

## 資料の見え方

- 記録は Project の `docs/cso-*` に、資料は HTML タブの「経営の資料（CSO）」に出ます。
- 数字には材料の出典が付き、事実・観測・推測・未確認を区別して表示します。材料がない数字は推定で埋めず「未確認」と表示します。
- 確定した記録は書き換えず、新しい版を作ります。HTMLで版を切り替えると、前の版との違い（文言と値の差）が表示されます。
- 月次の観測は月次の記録に残し、戦略を変えるのは四半期レビューです。

## 使い方

1. このエージェントを参加させたProjectで、「いま一番決めたいこと」と手元の月次の数字を渡します。
2. 計画を作った後、了承すれば毎月の会議を自動で始める設定をします。了承しなければ設定しません。自動で始まらなかったときは「月次会議をして」と頼んでください。

制作者が確かめたのは、通常のProjectで架空の物販事業の資料を使い、初回の相談から四半期レビューまでを一巡した範囲です。DM（1対1の会話）での利用は確かめていません。資料づくりを手伝うエージェントであり、売上や利益などの事業の成果を保証するものではありません。

## しないこと

値段の変更、メールの送信、支払い、公開はしません。下書きまでで、実行は利用者が行います。

## 必要なもの

- HTMLの書き出しに Node.js（18以上）を使います。
- 外部サービス（モール・会計など）とは接続しません。明細はファイルで渡してください。

## 中身

| 場所 | 内容 |
|---|---|
| `identity.md` | 役割と守る線 |
| `.agents/skills/cso-records/` | 記録の形・版の規則・HTMLの書き出し（計算・検査・テンプレート・架空の見本・テスト） |
| `.agents/skills/cso-direction/` | ミッション・ビジョン・経営方針と現状 |
| `.agents/skills/cso-strategy/` | 戦略と試し |
| `.agents/skills/cso-plan/` | 計画と予算 |
| `.agents/skills/cso-review/` | 月次経営会議と四半期レビュー、定期実行 |

見本（`fixtures/`）の事業・人物・数字はすべて架空です。

テスト：`node .agents/skills/cso-records/tests/unit.mjs`
